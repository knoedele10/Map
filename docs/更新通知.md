### 从源码构建安装包

构建环境：Windows x64、Go 1.25 或更新版本、Node.js 和 npm。

在 PowerShell 运行：

```powershell
cd A:\Map\desktop
npm install
npm run dist:win
```

`npm run dist:win` 会先编译 Go 后端，再由 Electron Builder 生成 NSIS 安装程序。输出路径：

```text
desktop/dist/Shuji-Rongbao-Setup-1.0.0.exe
```

Ollama 和项目配置的模型不包含在安装包中，需要在目标电脑另行安装。更多说明见 [`desktop/README.md`](../desktop/README.md)。
